# Security Policy

Developed and maintained by [IntrAgile Kft.](https://intragile.eu)

## Reporting a vulnerability

Please report security issues privately to **info@intragile.eu** rather than opening a public
issue. Include the affected version and, if possible, steps to reproduce. You will receive a
reply within a few working days.

## Scope

This package wires [intragile/php-text-extractor](https://github.com/intragile/php-text-extractor)
into Laravel. Parsing happens in the core package; issues with hostile files belong there, and the
same address reaches the same team.
